Автоматическая подборка «Перекусы для заморозки» отбирает только опубликованные рецепты категории `snack` со значением `storage.freezable: true`, сейчас четыре блюда. Ручная подборка «Перекусы в контейнер» содержит пять блюд в заданном порядке. «Перекусы за 15 минут» автоматически расширяется с семи до девяти рецептов; пудинг и кускус туда не попадают.

Время ориентировочное, учитывает отдых массы, разогрев, приготовление и указанное короткое охлаждение. Несколько партий аэрогриля, полное охлаждение батончиков для упаковки, размораживание замороженных палочек и подготовка замороженной брокколи займут дополнительное время. Быстрые способы используют охлаждённые готовые палочки, готовые консервы и свежие овощи. Кипячение воды для кускуса требует плиты, не помечено как «Без нагрева».

Все рецепты помечены `origin: ai`, `tested: false`. Изображения иллюстративные, не подтверждают приготовление. Калорийность и обещания похудения не добавлены. Пудинг содержит добавленный сахар, батончики арахис; сведения не скрыты.

## Хранение

Готовые блюда для заморозки хранятся закрытыми при температуре не выше +4 °C до двух дней, остальные до одного дня, с учётом более короткого срока на упаковке. Для четырёх замораживаемых блюд дан ориентир до одного месяца при -18 °C для качества, не предел безопасности. Замораживается готовое охлаждённое блюдо, не сырая куриная масса. Размораживание в холодильнике, для котлет и яичных маффинов повторный нагрев до 74 °C внутри. После заморозки текстура может стать мягче. Для перевозки нужен холод, а не просто контейнер.

Общие ограничения сверены с [FoodSafety.gov: безопасные температуры](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures) и [FoodSafety.gov: холодное хранение](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts). Курица полностью готовится до 74 °C; для порционной яичной запеканки также указан ориентир 74 °C. Мука в крекерах полностью пропекается, сырое тесто не пробуют. Сроки для конкретных рецептов консервативные редакционные ориентиры, не лабораторные измерения.

`npm test`, `npm run typecheck`, `npm run format:check`. После обновления контейнера: `SNACK_03_BASELINE_PATH=.local/qa/snacks-03-baseline.json node --env-file=.env scripts/verify-snacks-03.mjs`. Результат: 128 тестов в 15 файлах прошли, TypeScript и форматирование без ошибок, production-сборка успешна. API-проверка подтвердила восемь новых изображений WebP 1536x1024 и неизменность всех прежних 113 рецептов, 89 ингредиентов и 33 подборок по полному содержимому.

Подборки: заморозка четыре блюда, контейнеры пять, быстрые девять. Фильтр «Без нагрева» даёт десять перекусов, с ограничением до 20 минут девять; аэрогриль три. Журнал браузера без предупреждений и ошибок во время проверки.

Визуальная проверка: desktop 1440x1050, mobile 390x844 и 320x844, без горизонтального переполнения. Артефакты: `.local/qa/snacks-03-desktop.png`, `.local/qa/snacks-03-mobile.png`, `.local/qa/snacks-03-mobile-320.png`, `.local/qa/snacks-03-mobile-content.png`, `.local/qa/snacks-03-browser.json`.
