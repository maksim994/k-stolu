# Перекусы: первая партия

Новая категория `snack` добавлена в каталог, редактор рецептов, правила подборок и JSON-импорт/экспорт. В плане питания появился приём пищи «Перекус» между обедом и ужином. При переходе из рецепта этой категории форма сразу выбирает перекус; прежние записи плана сохраняют свои приёмы пищи.

## Рецепты

| Рецепт                                  | Техника             | Время, мин |
| --------------------------------------- | ------------------- | ---------- |
| Рулет из лаваша с тунцом и огурцом      | Без нагрева         | 15         |
| Творожный дип с огурцом и хлебом        | Без нагрева         | 10         |
| Фасолевая намазка с лимоном и хлебом    | Без нагрева         | 15         |
| Йогурт с яблоком и грецкими орехами     | Без нагрева         | 10         |
| Сэндвич с бананом и арахисовой пастой   | Без нагрева         | 10         |
| Горячие тосты с помидором и сыром       | Духовка             | 25         |
| Конвертики из лаваша с фасолью и перцем | Плита               | 25         |
| Запечённый нут с паприкой               | Духовка / аэрогриль | 50 / 35    |

Базовая партия — 2 порции. Бобовые консервированные, их масса указана без жидкости; сухие бобовые не считаются готовыми. Творожная и фасолевая намазки не требуют блендера. Для конвертиков учтены две последовательные партии на сковороде, для духовки и аэрогриля — разогрев и одна партия. При недостаточной вместимости время увеличивается.

Новый продукт: арахисовая паста. В рецепте с ней есть явное предупреждение об арахисе. Для йогурта указаны грецкие орехи и молочные продукты. Это не автоматический фильтр аллергенов и не обещание индивидуальной безопасности или снижения веса.

Всего в каталоге: 105 рецептов, 89 продуктов, 132 способа, 31 подборка. Прежние блюда не переносились из своих рубрик.

## Подборки

- «Перекусы за 15 минут»: автоматическая, 5 рецептов, только без нагрева.
- «Перекусы с собой»: ручная, 4 рецепта, с явными условиями охлаждения и перевозки.
- «Тёплые перекусы»: ручная, 3 рецепта.

На компьютере категории остаются в одном ряду из семи кнопок. На телефоне шесть прежних кнопок занимают два ряда, «Перекусы» — компактную строку с иконкой сэндвича.

## Хранение

У всех рецептов задан консервативный редакционный ориентир до 1 дня в холодильнике; заморозка собранного блюда не рекомендуется по текстуре. Это не результат лабораторной проверки. Короткий срок вскрытого продукта имеет приоритет. Тёплые остатки быстро охлаждают небольшими порциями; повторный разогрев — до 74 °C внутри.

Для еды с собой указано предварительное охлаждение и термосумка с двумя аккумуляторами холода, поддержание температуры не выше +4 °C и холодильник по прибытии. Обычная сумка не заменяет холодильник ([USDA: безопасная перевозка еды](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/keeping-bag-lunches-safe)). Общие ориентиры температуры холодильника и плохой переносимости заморозки смешанными блюдами сверены с [FoodSafety.gov](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts).

## Проверки

`SNACK_BASELINE_PATH=.local/qa/snacks-baseline.json node --env-file=.env scripts/verify-snacks.mjs` проверяет каталог, изображения и неизменность прежних записей относительно снимка перед добавлением.

Результат: 113 тестов прошли, TypeScript и форматирование успешны, production-сборка выполнена; оба Docker-сервиса healthy. API подтвердил 8 новых изображений и неизменность всех прежних 97 рецептов, 88 продуктов и 28 подборок.

В браузере проверены 8 страниц, 9 способов приготовления, изображения, блоки хранения и по 3 похожих перекуса. Подборки показывают 5/4/3 блюда; фильтр без нагрева — 5, аэрогриль — один рецепт с нужным способом. В форме плана автоматически выбраны «Перекус» и ранее выбранный аэрогриль; форма отменена без сохранения. Пересчёт намазки 2 → 3 → 2 проверен: 330 г фасоли и 120 г хлеба на 3 порции. При ширинах 1440, 390 и 320 px переполнения нет, все подписи категорий помещаются. Браузерных ошибок нет. Личные продукты, покупки, избранное и план не изменялись.

Финальная проверка интерфейса: единственное замечание к актуальности DESIGN.md исправлено, итог `clear`. Механический детектор сообщил рекомендации по существующим размерам шрифта и цветам старого CSS; новые цвета или размеры шрифта в этой итерации не добавлялись, несвязанные изменения не выполнялись.
