## Время и техника

Сэндвич рассчитан на сырые яйца с последующей варкой и охлаждением,
не выдаётся за холодную 10-минутную сборку. Овсяноблин учитывает набухание
мелких хлопьев и два последовательных блина на одной сковороде.
Для вафель предусмотрены две закладки по две вафли; прибор с одним
отделением потребует больше времени. Размеры и выход относятся к базовым
двум порциям, при увеличении нужны дополнительные закладки.

Мультиварка указана только для двух каш с отдельными шагами, без давления.
Нужно сверить допустимость состава и минимальный объём по инструкции;
слишком большую чашу для двух порций не рекомендуем. Молоко не оставляют
на отсроченном старте. Для шакшуки нужна готовая консервированная фасоль,
не сухая. Холодное творожное блюдо не содержит сырых яиц и использует
готовые к употреблению пастеризованные продукты.

## Статус и хранение

Все новые рецепты подготовлены ИИ, `tested: false`, реальная готовка
не проводилась. Нет рассчитанной пищевой ценности или медицинских обещаний.
«Без добавленного сахара» описывает состав, не означает отсутствие
природных сахаров или автоматическую пригодность для похудения.

Хранение в холодильнике указано ориентировочно на 1–2 дня при условиях
общего блока интерфейса: не выше +4 °C, в закрытой ёмкости, убрать в течение
2 часов после приготовления. Это осторожные редакционные ориентиры,
не лабораторная проверка каждой рецептуры. Основной источник общих условий:
[FoodSafety.gov: холодное хранение](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts).

Для яичных смесей используется ориентир 71 °C, для отдельных яиц —
полностью плотные белок и желток; для разогрева остатков — 74 °C.
Основа: [FoodSafety.gov: внутренние температуры](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures).
Время всегда сопровождается проверкой готовности, а не заменяет её.

Готовые вафли и конверты из лаваша допускают порционную заморозку до
1 месяца для лучшего качества. У молочных каш, собранных блюд с сырыми
овощами и творожной миски заморозка не рекомендуется по ожидаемой текстуре.
Это не утверждение об абсолютном запрете замораживания.
