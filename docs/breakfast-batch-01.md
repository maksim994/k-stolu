# Первая партия завтраков

Дата: 11 октября 2026. Добавлены 12 рецептов к 3 существующим завтракам. Всего в каталоге 22 рецепта и 6 подборок.

## Редакционные правила

Рецепты написаны с помощью ИИ для обычной домашней кухни, не проверены приготовлением. Поле `tested: false` показывается в рецепте и редактируется в админке. Данные о калорийности не выдумываются. Изображения сгенерированы отдельно для каждого блюда и обозначены как иллюстрации.

Различающиеся составы — самостоятельные рецепты; мультиварка и другие способы одного блюда — варианты. Время в карточке включает подготовку и ожидание, поэтому ночная овсянка не попадает в быстрые завтраки. Выход вафель и блинов указан приблизительно: зависит от размера прибора и толщины теста.

Ручные подборки сохраняют заданный порядок. Автоматические применяют все условия к одному варианту приготовления. Закреплённые рецепты не обходят правила. Черновики и архивные рецепты не попадают в публичные подборки или рекомендации. Импорт старого JSON без поля `collections` не удаляет подборки.

## Проверенные ориентиры

- [FoodSafety.gov: безопасные температуры](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures): для яичных блюд использован ориентир 71 °C, для запеканки 74 °C; цельное яйцо готовится до схватившихся белка и желтка.
- [FoodSafety.gov: хранение в холодильнике и морозильнике](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts): холодильник не выше 4 °C, морозильник −18 °C. Приведённые в рецептах короткие сроки — осторожные ориентиры, не лабораторная проверка каждого состава. Сроки в морозильнике относятся к качеству, не к гарантии безопасности. Не замораживать сэндвич с огурцом и йогуртовой начинкой — рекомендация по текстуре.
- [BBC Good Food: Classic waffles](https://www.bbcgoodfood.com/recipes/classic-waffles): сверены базовая структура теста и ориентир выпечки в разогретом приборе. Наш состав и текст авторские, адаптированные; опубликованные калории чужого рецепта не перенесены.

## Иллюстрации

Встроенный `image_gen`, по одному запросу на блюдо, без исходных изображений. Готовые файлы: `public/images/recipes/<recipe-id>.webp`. Оригинальные PNG сохранены в каталоге Codex generated_images; в проекте выполнено только перекодирование в WebP, без изменения композиции. Набор запросов записан в [breakfast-image-prompts.json](breakfast-image-prompts.json).

## Проверка

`npm test`, `npm run typecheck`, `npm run format:check` и `node --env-file=.env scripts/verify-collections.mjs`. Для проверки dev-сервера задайте `TEST_ORIGIN=http://localhost:3038`. Браузерный сценарий проверяет фотографии, подборки, способы приготовления, рекомендации, покупки, админку, совместимость старого импорта и мобильную компоновку. Созданная им временная подборка удаляется в `finally`.
